# New Design Brief: Astrological Luxury Theme

## Project Overview
Create a new web layout for CosmicSpiritGuide.com that embodies:
- **Astrological Theme**: Celestial bodies, constellations, cosmic elements
- **Apple Quality**: Clean, minimal, luxury aesthetic
- **Professional Presentation**: High-end spiritual guidance platform

## Design Principles

### Visual Identity
1. **Color Palette**
   - Deep space blues/navy
   - Gold accents (premium feel)
   - Celestial gradients
   - High contrast for readability
   - White/pure space for breathing room

2. **Typography**
   - Clean, modern sans-serif for body
   - Elegant serif for headings (optional)
   - Generous line spacing
   - Clear hierarchy

3. **Imagery**
   - Constellations
   - Celestial bodies
   - Astrological symbols
   - Abstract cosmic patterns
   - Subtle animations

### Layout Guidelines
1. **Homepage**
   - Hero section with constellation background
   - Preview of service offerings
   - Social proof/testimonials
   - Clear CTAs

2. **Navigation**
   - Clean, minimal header
   - Mobile-responsive hamburger menu
   - Footer with links

3. **Dashboard** (for logged-in users)
   - Personalized cosmic dashboard
   - Reading history
   - Birth chart visualization
   - Credit balance

4. **Service Pages**
   - Clear description
   - Pricing display
   - Booking/purchase flow

5. **Blog**
   - Clean reading experience
   - Featured images
   - Related posts
   - Social sharing

#### Components Needed:

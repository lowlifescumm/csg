## 🚀 Setup Instructions

### **1. Run Database Migration**
```bash
cd e:\merge\csg
node scripts/setup-blog.js
```

### **2. Access Your Blog**
- **Public Blog**: `https://cosmicspiritguide.com/blog`
- **Admin Panel**: `https://cosmicspiritguide.com/admin/blog`
- **Individual Posts**: `https://cosmicspiritguide.com/blog/[slug]`

### **3. Create Your First SEO Post**
1. Go to `/admin/blog`
2. Click "New Post"
3. Fill in SEO fields:
   - **Title**: SEO-optimized headline
   - **Meta Title**: 50-60 characters
   - **Meta Description**: 150-160 characters
   - **Tags**: Relevant keywords
   - **Category**: Content classification

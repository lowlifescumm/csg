# Google OAuth Setup Guide

This guide will help you set up Google OAuth authentication for your Cosmic Spiritual Guide application.

## Prerequisites

- Google Cloud Platform account
- Access to your Google Cloud Console

## Step 1: Create OAuth 2.0 Credentials

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Select your project or create a new one
3. Navigate to **APIs & Services** > **Credentials**
4. Click **Create Credentials** > **OAuth client ID**
5. If prompted, configure the OAuth consent screen:
   - Choose **External** (unless you're using a Google Workspace account)
   - Fill in app name, user support email, developer contact email
   - Add scopes: `email`, `profile`
   - Add test users (your email for testing)
   - Save and continue

## Step 2: Create OAuth Client ID

1. Select **Web application** as the application type
2. Add authorized redirect URIs:
   - **Development**: `http://localhost:5000/api/auth/callback/google`
   - **Production**: `https://yourdomain.com/api/auth/callback/google`
3. Click **Create**
4. Copy the **Client ID** and **Client Secret**

## Step 3: Configure Environment Variables

### Local Development (.env.local)

Add these to your `csg/.env.local` file:

```bash
# Google OAuth
GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-client-secret

# NextAuth Configuration
NEXTAUTH_URL=http://localhost:5000
NEXTAUTH_SECRET=generate-a-random-secret-here

# JWT Secret (should already exist)
JWT_SECRET=your-jwt-secret-here
```

Generate NEXTAUTH_SECRET:
```bash
openssl rand -base64 32
```

### Production (Render Dashboard)

Add these environment variables in your Render dashboard:

1. Go to your Render dashboard
2. Select your web service
3. Go to **Environment** tab
4. Add these variables:

```
NEXTAUTH_URL=https://yourdomain.com
GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-client-secret
```

**Note**: `NEXTAUTH_SECRET` is auto-generated by Render if configured in `render.yaml`

## Step 4: Database Setup

Ensure your database has the required columns for Google OAuth:

Run the migration script:

```bash
cd csg
psql $DATABASE_URL -f database/add-google-oauth.sql
```

Or manually execute the SQL from `database/add-google-oauth.sql` in your database.

The migration adds:
- `google_id` column (unique)
- `avatar_url` column  
- `email_verified` column
- `updated_at` column (if missing)
- Makes `password_hash` nullable for OAuth users

## Step 5: Verify Setup

Run the verification script:

```bash
cd csg
node scripts/verify-google-oauth-setup.js
```

This will check:
- ✅ Environment variables are set
- ✅ Database schema is correct
- ✅ NextAuth configuration file exists

## Step 6: Test Google Sign-In

1. Start your development server:
   ```bash
   npm run dev
   ```

2. Navigate to `/login`
3. Click "Sign in with Google"
4. Complete the Google OAuth flow
5. You should be redirected to `/dashboard`

## Troubleshooting

### "Invalid OAuth Credentials" Error

- Verify `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET` are correct
- Check that redirect URIs match exactly in Google Console
- Ensure no extra spaces in environment variables

### Database Errors

- Run the migration script: `psql $DATABASE_URL -f database/add-google-oauth.sql`
- Check that `password_hash` column is nullable
- Verify all Google OAuth columns exist

### "Failed to sign in with Google"

- Check server logs for detailed error messages
- Verify `NEXTAUTH_URL` matches your actual domain
- Ensure `NEXTAUTH_SECRET` is set
- Check that Google OAuth consent screen is configured

### User Creation Fails

- Check that `users` table exists
- Verify `email` column is unique
- Check server logs for database errors

- [ ] Environment variables set in Render dashboard

## Security Notes

- Never commit `.env.local` or `.env` files to git
- Use strong, randomly generated secrets
- Regularly rotate OAuth credentials
- Monitor for unauthorized access
- Keep dependencies updated
